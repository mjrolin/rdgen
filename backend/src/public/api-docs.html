🚀 RDGen API Documentation

Build custom RustDesk clients with your own branding and configuration

📚 Guia Rápido de Integração

🔑 Autenticação

Use header X-API-Key para autenticação multi-tenant ou Authorization: Bearer para sessão web.

🏗️ Iniciar Build

POST /api/build com BuildConfig no body. Retorna jobId para acompanhamento.

📊 Acompanhar Status

GET /api/status/{jobId} retorna progresso e status atual do build (0-100%).

⬇️ Download

GET /api/artifact/{jobId}?type=exe após status=completed para baixar o executável.

🔗 Token de Conexão

POST /api/token/generate gera token temporário para conexão automática via RustDesk.

🎨 Display Settings

Configure qualidade de imagem, codec (VP9/H264/H265), FPS (15/30/60) e modo de display.
